About This Workload

Project purpose, architecture overview, and API endpoint reference

Cloud Infrastructure Workload Purpose

The Cloud Infrastructure Dashboard is a functional, lightweight workload designed specifically for cloud infrastructure deployment projects. It acts as an operational service to validate cloud provisioning (e.g. AWS EC2, Elastic Container Service, Application Load Balancers, Target Group health checks, and Auto Scaling groups).

Zero Mock Data: All metrics, uptimes, and memory allocations are accurately calculated from genuine Node.js standard libraries (os and process).
Unified Architecture: A single Express.js process serves both static HTML/CSS/JS assets and REST API endpoints.
Infrastructure Ready: Provides an industry-standard GET /api/health endpoint for load balancer health checks and automated probes.
REST API Endpoints Reference
Method Endpoint Description Response Format Expected Status
GET /api API catalog listing available service endpoints and status application/json 200 OK
GET /api/health Application health status, current timestamp, version, and uptime application/json 200 OK
