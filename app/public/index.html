Workload Architecture

Mission Brief & Cloud Workload Context SPECIFICATION

The Cloud Infrastructure Dashboard is a lightweight, responsive operational workload engineered to validate cloud infrastructure provisioning across AWS EC2, Elastic Container Service, Target Group health check probes, and Auto Scaling clusters.

✦
Zero Mock Telemetry

All CPU metrics, memory allocations, and uptimes reflect genuine Node.js standard library kernel calls without arbitrary numbers or simulated values.

✦
Unified Express Architecture

A single Express.js instance concurrently serves static HUD assets and genuine REST API endpoints with minimal resource overhead.

✦
Load Balancer Ready

Features an industry-standard GET /api/health endpoint returning HTTP 200 for Application Load Balancers and automated orchestration health probes.
